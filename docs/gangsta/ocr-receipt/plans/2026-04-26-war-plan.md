## Work Packages

### WP-001: Backend OCR Service
**Territory:** Backend API
**Contract Clause:** FR-002, FR-003, FR-004, FR-008
**Files:**
- Create: `backend/services/ocr.ts`
**Acceptance Criteria:**
1. Exports `OcrService` interface with `extractReceipt(filePath: string): Promise<ReceiptExtract>`
2. Ollama implementation constructs structured prompt with available categories and currencies
3. Prompt instructs model to return only JSON: amount (numeric string), currency (ISO 4217), date (YYYY-MM-DD), description, category (from allowlist or null)
4. Post-processing validates with Zod, runs sanity checks (amount > 0 and < 1_000_000, date within last 5 years, currency in known set)
5. Returns `{ amount, currency, date, description, category, confidence: 'high' | 'medium' | 'low' }`
6. `MockOcrService` exported for testing
**Verification:** `bun run --cwd backend build` compiles without errors
**Budget:** 1000 tokens
**Dependencies:** WP-002

### WP-003: Backend OCR Route + Receipt Serving
**Territory:** Backend API
**Contract Clause:** FR-002, FR-004, FR-007, NFR-001, NFR-003, NFR-004, NFR-005
**Files:**
- Modify: `backend/routes/transactions.ts`
**Acceptance Criteria:**
1. `POST /api/ocr` added (auth-protected, multipart, maxBodySize: 10MB)
2. MIME type validation against `['image/jpeg', 'image/png', 'image/webp']` before disk write
3. Extension extraction via `path.extname()` + regex sanitization `/[^a-z0-9]/` + allowlist (`jpg`, `jpeg`, `png`, `webp`); rejected extensions return 400
4. UUID-based temp filename written to `data/temp_receipts/${uuid}.${ext}`
5. Calls `OcrService.extractReceipt(tempPath)` and returns `{ suggestion: result }`
6. `GET /transactions/:id/receipt` registered **before** `GET /:id` in the Hono router
7. Looks up stored receipt file at `data/receipts/${id}.${ext}` (ext resolved from stored reference or filesystem lookup)
8. Returns file with explicit `Content-Type` from extension map and `X-Content-Type-Options: nosniff`
9. On transaction creation (`POST /transactions`), if `receiptTempId` provided in body, moves temp file from `data/temp_receipts/${receiptTempId}.${ext}` to `data/receipts/${transaction_id}.${ext}`
**Verification:** `bun run --cwd backend test` includes at least one OCR route test
**Budget:** 1200 tokens
**Dependencies:** WP-001, WP-002
