### WP-009: Backend — Auth routes (login, refresh, logout, change-password)
**Territory:** Backend Auth & API
**Contract Clause:** FR-001, FR-003, FR-003a, FR-004, FR-005
**Files:**
- Modify: `backend/routes/auth.ts`
**Acceptance Criteria:**
1. `POST /auth/login` validates credentials, returns `{ token, refreshToken }`; stores refresh token hash in DB; rate limited 10/15min
2. `POST /auth/refresh` validates refresh token hash, uses `BEGIN IMMEDIATE` transaction for atomic rotation, returns new `{ token, refreshToken }` pair; old token deleted; rate limited 30/15min
3. FR-003a: If an invalidated/stale refresh token is resubmitted, ALL refresh tokens for that user are revoked (theft detection)
4. `POST /auth/logout` (auth required) deletes refresh token from DB
5. `POST /auth/change-password` (auth required) validates current password, updates hash, revokes all refresh tokens
6. Refresh tokens are opaque UUIDs, hashed with SHA-256 for storage
7. Access tokens are JWTs with `{ sub: userId, role, exp }`, 15-minute expiry
8. Refresh tokens have 7-day expiry; expired tokens cleaned on lookup
**Verification:** Integration test: login → use token → refresh → old token rejected → logout → refresh fails
**Budget:** high
**Dependencies:** WP-002, WP-007, WP-008
